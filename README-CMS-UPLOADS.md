# Portfolio image uploads in Pages CMS

Open **Portfolio content** to edit the portfolio. The image controls are inside the relevant sections of that content form:

- **Profile and hero**: Brand logo, Profile photo, Hero background, Availability background, Contact background.
- **Projects**: Each project has its own Project cover image and Project gallery screenshots controls inside Project details.

The media libraries are separated by purpose. Uploaded files are stored in matching folders under `assets/media/`, so logos, profile photos, backgrounds, project covers, and galleries do not all mix together.

After uploading, select/save the image in its matching field, then save the Portfolio content file.
